# editor-minmd v0.1.1

发布日期：2026-10-17。

本版扩展 Markdown 阅读能力：复杂语法可以直接查看，修改时使用源码模式。文档模式继续保留安全转换检查，避免有损编辑。

## 新增

- 阅读模式独立解析当前 Markdown 原文，支持脚注编号和往返跳转、行内与块级数学公式、GitHub 提示块、带类型的自定义容器。
- 支持 `[[文件]]`、别名、标题定位，以及本地图片和 Markdown 文档嵌入；文档嵌入可只显示指定章节，包含循环引用、层级、数量和大小保护。
- 安全展示内嵌 HTML，支持 details/summary 等结构；过滤脚本、事件和危险内容，原文中的注释继续保留。
- 扩展阅读保留大纲、查找、代码高亮/复制和 Mermaid；错误公式、无效图表、未知代码和资源读取失败提供局部回退。

## 修复与原文保护

- 修复行内代码中的 `<version>`、脚注示例和转义标记被误判为特殊语法。
- 特殊语法允许进入阅读模式，进入文档编辑受限时只显示一条保护提示。
- 修复源码修改经过阅读模式后可能复用旧文档内容的问题，保留无修改切换时的撤销历史。
- 阅读、查找、无修改保存不改写文件；源码修改后，阅读与保存使用最新内容。保留 BOM、Frontmatter、CRLF 和原有空白。
- 跨目录另存为时同步改写双链与嵌入文件路径，保留别名、标题及代码示例。

## 下载与安装

在 [v0.1.1 Release](https://github.com/tingxi8087/editor-minmd/releases/tag/v0.1.1) 下载：

| 附件 | 用途 |
| --- | --- |
| `editor-minmd_0.1.1_aarch64.dmg` | macOS Apple Silicon 安装包，打开后拖入「应用程序」 |
| `editor-minmd_0.1.1_aarch64-apple-darwin.zip` | 同架构应用 ZIP，解压使用 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验清单 |
| `build-info.json` | 版本、目标架构与构建时间 |

本版仅提供 macOS Apple Silicon（M 系列芯片）。应用未经过 Apple Developer ID 签名与公证；确认来自本仓库后，可按 macOS 提示在「系统设置 → 隐私与安全性」允许打开。Intel Mac、Windows 和 Linux 暂无本版安装包。

## 验证与范围

前端 24 个文件 / 349 项测试、Rust 46 项测试通过；TypeScript 与 release 桌面打包通过，版本元数据、ARM64 可执行文件、DMG 与 ZIP 完整性均已核对。扩展阅读的 macOS 隔离应用实测和逐字节文件保真验收见[详细说明](https://github.com/tingxi8087/editor-minmd/blob/v0.1.1/doc/reading-mode.md)。

扩展语法本版仅支持阅读渲染，修改使用源码；未知方言不承诺专有排版。单个嵌入文档最多 1 MiB，最多展开 3 层、12 个嵌入，嵌入总文本最多 1,000,000 字符。嵌入文件没有单独的实时监听，重新进入阅读会重新读取。
