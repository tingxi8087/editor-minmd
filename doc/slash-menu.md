# 斜杠插入与 Mermaid 图形

实现与验收日期：2026-10-16。

## 插入菜单

在可编辑的文档段落开头输入 `/` 显示完整菜单，可继续输入中文、英文或拼音关键词过滤。支持 ↑↓ 选择、Enter 插入、Escape 关闭；输入法选字不触发提交。菜单随光标定位，在窗口底部向上展开，限制高度并支持滚动，浅深色继承纸墨主题。

共 20 项：

| 类型 | 选项 |
| --- | --- |
| 基础 | 正文、标题 1—6、引用、分割线 |
| 列表 | 无序列表、有序列表、任务列表 |
| 内容 | 代码块、Mermaid 图表、三行三列表格、图片 |
| 行内插入 | 表情、日期、引用文档、插入链接 |

正文中空格后或标题内的 `/` 仅提供四项行内插入，避免改变整段结构。代码块、源码模式、阅读模式、只读指南及非活动标签不弹菜单。Escape 关闭后，同一查询的选区/元数据事务不会立即重新弹出，修改查询可再次触发。

- 普通块操作在同一事务中删除命令并插入内容；与刚输入命令的历史隔开，一次撤销恢复完整 `/query`。
- 图片、表情、日期和链接等选择流程确认成功前保留命令，取消不丢正文。弹窗不因点击遮罩关闭。
- 表情提供五个分类、跨分类关键词搜索、最近 8 项，直接插入 Unicode 字符；日期插入普通 `YYYY-MM-DD` 文本，默认本机当天。
- 图片复用原生选图与 `assets/` 导入。未命名文档先保存；取消保存/选图保留命令。若另存成普通文本文件导致退出文档模式，则停止插图。
- 普通链接支持网页、相对文件路径和标题锚点。引用文档使用系统文件选择器，仅选本地 Markdown，插入标准相对路径链接，中文、空格、`#` 和括号正确编码。当前文档须先保存，引用选择不使用 minmd 的空间或文档 ID。
- 弹窗绑定原标签、编辑器与正文快照；切标签、切模式、关闭、正文变化或异步选择过期时丢弃结果，防止误插到其他内容。另存为继续沿用原资源基准和现有重定位机制。

## 代码块与 Mermaid

普通代码块保留语法高亮，块头提供语言选择和复制；语言变化可撤销，复制只取代码正文，不改变文档。阅读模式显示语言名称并保留复制。

`/mermaid` 插入带初始示例的 `mermaid` 围栏代码块。编辑模式显示源码和图形，阅读模式默认显示图形，并可点击「查看源码」。修改源码后防抖更新图形；语法错误显示提示并保留源码，修正后可再次渲染。保存仍是普通 Markdown 围栏，不存 SVG、私有节点或生成图形。

Mermaid 按需加载，图形在本机生成，无远程图表服务。使用 strict 配置、禁 HTML 标签与用户配置指令，不调用图形交互绑定；生成 SVG 作为图片上下文显示，不将图形作为可交互 HTML 挂进正文。小图按固有尺寸居中，大图按宽度缩小，长图预览区限制 480px 并可滚动。

渲染串行执行，250ms 防抖，缓存最近 24 个图形结果并区分浅深色；过期结果和已销毁编辑器不更新界面。当前限制源码 30,000 字符、流程图 300 条边；不支持 Mermaid frontmatter 与 `%%{...}%%` 自定义配置，避免绕开渲染配置。错误图仅影响预览，源码可以继续保存和复制。

- Rust 31 项通过。新增真实文件引用测试验证特殊文件名相对 URI、二进制/非 Markdown/缺失文件拒绝，其余文件与资源测试继续通过。
- 浏览器实际渲染中文流程图与时序图；验证小图不放大、深色阅读、源码查看及错误提示。渲染测试使用真实 Mermaid，单测中的异步渲染另有可控替身。
- macOS 独立 QA 桌面窗口：打开含两类 Mermaid 的 Markdown，均有图形；原生选择中文/`#`/括号文件名，插入相对引用、保存，并在阅读模式点击打开目标标签；关闭主文件再重开，图形与引用仍正常。真实磁盘核对两个围栏与编码后的链接一致。
- 桌面图片流程：从 `/image` 打开原生选图，取消保留命令；再次选择 PNG，图片复制到 `assets/` 并替换命令；一次撤销恢复 `/image`，重做保存后核对图片文件与相对引用。原生 WebView 代码复制显示成功，复制不使已保存文档变脏。
- 使用独立应用标识、空文件关联声明和独立恢复库的 QA 包测试，没有停止或接管用户已有开发进程。正式 release 通过 `npm run build` 更新 `build/<版本>/<目标>/`。
