# 最近文件与最近目录

更新日期：2026-10-16。

顶部「打开目录」右侧的时钟图标打开「最近打开」。弹层按最近文件、最近目录分组，显示名称和父路径，悬停可查看完整路径；不新增常驻侧栏或工具栏行。

## 行为

- 文件最多 20 条，目录最多 10 条；规范化绝对路径去重，最近成功使用的排在最前。
- 文件从打开对话框、文件树、本地链接或系统打开进入工作台时记录；新文档首次保存、另存为后也记录。取消操作、未命名草稿和内置指南不记录。
- 打开目录后记录；点击最近目录切换文件树并显示文件侧栏，保留所有已有标签及未保存修改。
- 最近文件已在标签中时直接激活，保留当前内容、选区和撤销历史，不用磁盘内容覆盖。
- 失效、无权限、非文本或超限文件显示错误，保留记录供重试或手动移除；目录打开失败保留当前工作目录。
- 单项移除和清空仅影响记录，不删除文件、不关闭标签。记录库损坏时可用「清空记录」重建。
- 应用内文件树重命名同步历史路径，移到系统回收站同步清理对应文件/子目录记录；外部移动不猜测新位置。
- 支持 Esc 和点击外部关闭、键盘 Tab 导航、返回触发按钮焦点。操作期间禁用重复打开和清理。

## 持久化与边界

原生应用数据目录内 `recents.json` 独立保存元数据，只含路径和名称。由 Rust 串行访问并以同目录临时文件原子替换；前端串行处理加载/写入结果，避免旧数据覆盖新记录。历史写入失败单独提示，不撤回已经成功的打开、保存或文件操作。

记录必须来自已授权打开/保存的文件或当前工作目录；重新打开只能使用库中登记的路径，重新验证真实路径和类型，沿用正文 UTF-8、NUL 与 16 MiB 限制。浏览器预览只展示空列表，本地持久化和重开需要桌面应用。

最近记录提供手动继续工作的入口；现已补齐独立的[重启工作区恢复](workspace-session.md)，清空最近记录不影响工作区恢复。
