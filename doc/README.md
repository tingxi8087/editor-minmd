# 项目文档

更新日期：2026-10-17。

editor-minmd是一个 MIT 开源的本地桌面文本编辑器，主要用于查看和编辑 Markdown，兼顾普通文本和代码阅读。当前已跑通本地 Markdown 的打开、所见即所得编辑和保存，并支持打开目录、按需展开文件树及多标签独立编辑；现已补齐本地图片、剪贴板插图、链接操作、另存为资源路径处理，以及草稿恢复和已打开文件的外部修改监听。Markdown 源码、普通文本与代码现使用 CodeMirror 6 编辑，包含行号、语法高亮和中文查找替换。文件树已提供新建文件/文件夹、重命名和系统回收站删除。

## 状态约定

- **已实现**：当前源码有完整入口和对应行为；具体运行验证范围见实现现状。
- **部分实现**：已有基础能力，但缺少用户操作入口、完整流程或必要验证。
- **待实现**：设计中已提出，目前尚未落地。
- **暂不纳入**：当前产品方向不计划提供，不作为欠缺功能积累。

设计文档描述目标，不能据此认定功能已完成。源码、测试和实际桌面行为用于核对当前状态；功能变更后同步更新对应条目。验证结果带日期，不自动代表后续版本仍已通过。

## 当前界面

当前采用紧凑纸墨布局，macOS 窗口按钮和打开文件、打开目录合并在顶部同一行，新建 MD 与文本使用左侧两个图标；左侧移除「已打开」列表，顶部标签承担打开文件导航。背景设置使用底部入口和小浮层。
