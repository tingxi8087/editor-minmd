# 项目文档

更新日期：2026-10-15。

MinMD · 纸墨是一个 MIT 开源的本地桌面文本编辑器，主要用于查看和编辑 Markdown，兼顾普通文本和代码阅读。当前已跑通本地 Markdown 的打开、所见即所得编辑和保存，并支持打开目录、按需展开文件树及多标签独立编辑。

| 文档 | 内容 |
| --- | --- |
| [设计方案](design.md) | 产品定位、交互与视觉方案、技术边界，以及已经调整的早期方案 |
| [实现现状](status.md) | 已实现、部分实现、现有限制、源码入口及验证范围 |
| [待实现清单](roadmap.md) | 后续任务、建议顺序和验收条件 |

阅读顺序建议：先看实现现状，再按待实现清单选择下一项；做技术或交互调整时对照设计方案。

## 状态约定

- **已实现**：当前源码有完整入口和对应行为；具体运行验证范围见实现现状。
- **部分实现**：已有基础能力，但缺少用户操作入口、完整流程或必要验证。
- **待实现**：设计中已提出，目前尚未落地。
- **暂不纳入**：当前产品方向不计划提供，不作为欠缺功能积累。

设计文档描述目标，不能据此认定功能已完成。源码、测试和实际桌面行为用于核对当前状态；功能变更后同步更新对应条目。验证结果带日期，不自动代表后续版本仍已通过。
