# 标签右键与统一 Markdown 模式

更新日期：2026-10-16。保持现有紧凑标签栏，无新增常驻区域。三种模式入口已合并为 Paper Ink Select 组件，显示当前图标与模式；下拉项带图标和选中标记，沿用纸墨浅/深色。

## 标签右键

右键顶部标签（包含文件名、图标和关闭按钮区域）显示中文菜单，替代系统文字菜单：

| 操作 | 范围 |
| --- | --- |
| 关闭其他 | 保留右键点中的标签，关闭其余标签 |
| 关闭左侧 | 关闭该标签左边的所有标签 |
| 关闭右侧 | 关闭该标签右边的所有标签 |
| 全部关闭 | 关闭所有标签，工作目录保留 |
| 关闭已保存 | 关闭所有没有未保存修改的标签，包括干净的未命名页/指南；保留已有路径但仍有修改的文件 |

右键不会主动激活点中的标签。左/右以右键目标为准，与当前激活标签无关。没有可关闭对象时对应项禁用；保存或关闭确认期间禁用菜单与标签操作。

批量关闭进入原有关闭计划，未保存的文档逐份确认，可保存、放弃或取消；全部确认前不移除任何标签，保存取消/失败不会直接删除标签。已关闭标签同步工作区记录。窗口退出仍走原有保留工作区机制。

菜单靠近窗口边缘时自动移入可见区域，支持上下方向键、Home/End、Enter、Escape、Tab；Shift F10 可在聚焦标签时打开，Escape 返回该标签焦点。点击外部、滚动或窗口缩放收起菜单。菜单沿用纸墨浅/深色。

## 三种模式统一

文档、阅读、源码是一个统一的 Markdown 显示偏好。在标签栏的单个下拉选择框选择「文档 / 阅读 / 源码」，或按 ⌘/Ctrl 1/2/3，会同步所有已打开 Markdown 标签；之后打开的文件、新建 Markdown 和重启恢复的文件沿用同一模式。激活其他标签不会改回旧模式。各标签的内容、未保存状态、各自编辑会话仍独立。

偏好使用现有 Zustand 设置存储 `minmd-appearance` 的 `markdownMode` 字段持久化。初次或无效值默认文档模式。旧工作区记录中的逐标签模式不再控制恢复显示，文件顺序/激活文件恢复保持原逻辑。恢复草稿保留正文权威来源，再应用当前统一模式。

普通文本/代码始终用源码。含脚注等当前富文本无法安全承载语法的 Markdown 继续用源码，避免损坏内容；在这些标签上主动选择文档/阅读失败时沿用原偏好并提示原因。仅切换模式不会把干净文件标成未保存。
