# 源码、普通文本与代码编辑

实现与验证日期：2026-10-15。使用 CodeMirror 6，沿用紧凑纸墨布局；源码工具栏替换格式工具栏，不额外增加常驻行。

## 操作

- Markdown（`.md`、`.markdown`、`.mdown`）首次默认所见即所得，标签行提供「文档 / 阅读 / 源码」。2026-10-16 起三种模式为全局偏好，切换会同步所有 Markdown 标签，新打开/新建及重启恢复也采用该模式；普通文本/代码仍用源码。详见[统一模式](tab-actions.md)。
- 普通文本、配置和代码文件直接进入 CodeMirror；独立打开文件与目录树使用相同流程。
- 左侧加号、菜单「新建 MD」和 ⌘/Ctrl N 创建 `未命名.md`，沿用全局 Markdown 模式；左侧「新建文本」和 ⌘/Ctrl Shift N 创建无后缀的 `未命名`，默认源码编辑。两类分别编号为 `未命名 2.md` / `未命名 2`，避开已有标签重名。保存时沿用当前建议名称，文本不自动加 `.txt`，可自行输入扩展名。
- 行号、活动行、括号匹配、Tab 两空格缩进、可折叠语法块、独立撤销/重做、行列状态已接入。
- ⌘/Ctrl F 打开文件内查找替换，支持大小写、正则、整词；Escape 关闭；面板控件、选项及折叠提示已中文化，详见[中文化记录](file-management.md)。自动换行开关只影响当前标签显示。
- 按文件名识别语言并按需加载解析器。工具栏可选自动、纯文本、Markdown、JS/JSX、TS/TSX、JSON、HTML/CSS、Rust、Python、Shell、YAML、SQL；其他扩展名也使用 CodeMirror language-data 的匹配结果。未知扩展名回退纯文本；加载失败提示后仍可编辑。
- 源码沿用保存、另存为、未保存标记、逐标签关闭保护、草稿与外部监听。语言/换行显示调整不标记文件修改，不执行代码，也不提供 LSP、补全或调试。

语言元数据和解析器来自 [CodeMirror](https://codemirror.net/docs/ref/)。当前按需拆分语言包，主工作台包仍有 Vite 体积警告。

## 内容同步与撤销

每个标签保存原文件快照、当前文本和内容权威；富文本与源码不能同时编辑。切换仅同步内存，不自动保存原文件。

1. 打开 Markdown 时保留原始文本。没有实际正文修改的阅读/模式切换不会用富文本导出覆盖源文本。
2. 源码修改后，当前文本为权威。回到文档时先检查可支持语法，再解析正文；仅查看文档或保存仍使用原源码，直到真正发生富文本修改。
3. 富文本修改后，以其导出为权威；切回源码时更新 CodeMirror。富文本编辑可能规范化 Markdown 写法，这是原有文档模式的边界。
4. 单纯切换标签或未修改的模式切换保留各自历史和选区；另一模式实际修改后，目标模式内容变化则重建目标编辑器，重置其历史和选区。两个内核不共享连续撤销，也不映射语义光标。富文本撤销回解析基点时重新采用对应原始源码。
5. 模式内保留滚动位置；外部重新载入使用新磁盘内容重建会话，不允许撤销回被替换的旧版本。关闭标签时销毁两个编辑器。

## 文件与语法保护

- 读取普通 UTF-8 文件，上限 16 MiB；拒绝目录、无效 UTF-8 和含 NUL 的疑似二进制内容。目录内符号链接继续禁用。读取上限不是大文件性能承诺。
- 源码保存不经过 Markdown 富文本序列化。保留 BOM、原 LF/CRLF 类型、原始空格和末尾空行；实际编辑后混合换行统一为检测到的类型。不编辑则保存原始字节。
- 脚注、数学块、内嵌 HTML、提示块等被现有规则检出时，直接进入可编辑源码；尝试进入文档会提示保护原因；阅读模式现可独立解析原文，见[扩展阅读](reading-mode.md)。检测仍不是完整方言识别器。
- 普通文本中的 `**标记**`、HTML 或代码内容按字面保存。另存为改扩展名会更新文件类型和高亮；由普通文本变为 Markdown 时保持源码，之后可手动进入文档。
- 源码 Markdown 跨目录另存为，使用 Lezer Markdown/GFM 语法树只定位链接、图片和引用定义的 URL。路径改写沿用已有本地资源服务，其余字符保持；跳过 Frontmatter、代码、HTML 和脚注定义，不解释自定义附件语法。此时若引用改变，重建源码历史，避免撤销回旧目录引用。普通文本与代码不会进行资源路径改写。
- 本轮没有引入编码选择、目录搜索、显式跳转行入口、完整多光标交互说明或大文件性能优化。

## 草稿和外部变更

恢复记录增加可选 `kind`、`mode`、`authority`、`sourceScrollTop`。源码权威时保存字面文本与源码光标位置，恢复为同一类型/模式；富文本权威仍使用 JSON 结构快照。兼容旧记录，恢复不包含撤销历史、语言手动选择和换行显示偏好。

干净的文本/代码自动载入外部新版本；有本地修改时保留源码，提示对比/重载/另存副本。保存仍对比原磁盘快照。具体防抖、失败与竞态边界沿用[可靠性说明](reliability.md)。

- `cargo test --manifest-path src-tauri/Cargo.toml`：18 项通过，新增普通代码原样读写及 NUL/大小/目录保护；原目录、资源、原子保存、恢复和系统监听测试继续通过。
- `npm run build` 和 `npx tauri build --debug --bundles app`：通过，产出本机 macOS 调试应用。
- macOS 原生窗口：实测目录打开 TS/普通文本/长 Python/Markdown，以及无目录时通过原生对话框独立打开 TS；浅色/深色高亮和行号、此前的新建文本快捷键与 `.txt` 建议文件名（现已改为无后缀）、⌘S、⌘Z/重做、查找定位、手动语法选择、标签切换保留长代码滚动；核对保存后的磁盘内容、Markdown 源码空白与文档同步、脚注转换保护、二进制拒绝打开。
- 代码文件外部更新：干净标签自动载入；脏标签保护并禁止保存覆盖。两份源码草稿（TS 和含脚注 Markdown）落盘后 SIGKILL，重启逐份恢复，源码/模式/光标和代码冲突仍在；脚注保存、代码另存 `.ts` 副本均成功，原代码外部版本保持。验收前恢复库为空，验收后清理为空。
