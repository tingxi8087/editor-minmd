# 目录内文件管理与界面中文化

实现与验收日期：2026-10-15。

## 紧凑入口

文件树根行提供「新建文件」「新建文件夹」图标，不增加常驻工具栏。每项悬停/键盘聚焦显示「更多操作」，也可右键打开菜单；文件夹中可新建子项，文件和文件夹可重命名、移到回收站。工作目录本身只提供新建入口，不能从这里改名或删除。

新建文件默认建议 `未命名.md`，名称可直接带 `.txt`、`.ts` 等扩展名。成功后读取并打开文件；新建文件夹自动展开。新建空文件会立即写到磁盘，后续正文仍手动保存。

名称对话框支持 Enter 确认、取消；重命名时点击遮罩保持窗口和已输入名称，使用取消或关闭按钮退出；输入法组合输入期间 Enter 不提交。菜单支持方向键、Home/End 与 Escape；文件树主行聚焦时 F2 重命名。行内按钮保持 22px 宽，树行维持 27px，菜单按当前窗口边界定位。

## 重命名与会话

- 仅同一父目录改名，不提供移动或拖拽重排。现有目标拒绝覆盖；macOS/Linux 使用系统独占重命名原语，Windows 使用系统不覆盖行为。仅改大小写且文件系统认为重名时，先改成临时名称再改回。
- 文件夹改名会同步所有已打开子文件的路径、资源基准、保留登记路径、文件树缓存、展开状态、监听路径和恢复草稿。普通同类型改名保留当前内容、选区、滚动与撤销历史。
- 扩展名改变文件类型时，先保留当前文本，再进入对应源码编辑器；目标编辑器历史重建。由普通文本改成 Markdown 仍停留源码，可手动进入文档。
- 未保存内容不因改名写回原文件。改名前先等待草稿落盘；失败则取消磁盘操作。改名后同步写入新路径草稿，若恢复库此时失败，保留当前会话并沿用草稿失败提示/重试。
- 操作前校验已打开文件的原始磁盘快照，磁盘已变化则拒绝，先处理外部修改；异步旧监听结果不能覆盖改名后的状态。
- 不自动重写其他文档指向旧名称的链接，也不重写被改名目录中指向外部位置的相对链接。此能力是文件系统改名，不是引用重构。

## 系统回收站与保护

点击「移到回收站」后明确确认文件或整个文件夹及其内容。调用 [trash](https://docs.rs/trash/5.2.9/trash/) 的系统回收站功能；失败提示后保留原文件，不降级为永久删除。

- 存在未保存子文件时阻止删除，先保存或关闭这些标签，再重试。
- 有待处理的恢复草稿，或其他标签仍以此位置为资源基准时，先提示处理相关草稿/标签。
- 成功后关闭被回收的干净标签，清除对应树缓存和展开状态，并更新原生文件登记与监听；其他标签保留。
- 文件恢复使用系统回收站。macOS 本轮实际验证了访达「放回原处」；恢复后手动刷新文件树再打开。应用不提供自己的回收站或撤销删除栈。
- macOS 当前使用库的默认 Finder 后端，首次使用时系统可能请求控制访达；权限或系统回收站不可用时返回错误。

所有原生变更都核对当前工作根目录；拒绝根目录本身、越界路径、`.` / `..` 层级及符号链接组件。新建使用 `create_new` / `create_dir`，重名不覆盖。名称拒绝空白、控制字符、路径分隔符、跨平台保留字符/设备名、尾随空格或点。符号链接项当前不提供管理操作。

操作期间锁定编辑与其他文件变更；目录切换受原生根目录锁和前端忙碌状态保护。这里没有跨进程目录锁，路径组件被其他进程并发替换等文件系统竞态不宣称完全消除。

## 中文化

通过 CodeMirror `EditorState.phrases` 覆盖原生文案，包含查找/替换占位、下一个、上一个、全选匹配、区分大小写、正则表达式、全字匹配、全部替换、关闭、行跳转、折叠提示和无障碍播报。自动纯文本语言名也显示为中文；TypeScript、JSON、UTF-8 等技术名称保留。

查找栏使用紧凑 26px 控件和纸墨主题色，不额外挤占编辑区。操作系统自己的文件选择器和权限对话框随系统语言显示，不修改系统语言。

- `cargo test --manifest-path src-tauri/Cargo.toml`：22 项通过。新增 4 项原生测试覆盖中文新建、重名不覆盖、非法名称、非空文件夹/文件改名、系统独占改名冲突、磁盘快照、根目录/越界/符号链接保护和回收站失败。自动测试用可控替身验证回收站失败/成功调度，不会批量修改真实系统回收站。
- `npm run build`、`npx tauri build --debug --bundles app`：通过；本机 macOS 调试应用已更新。Vite 主包大小警告仍存在。
- macOS 真窗口：根行新建文件夹、子目录右键新建 `.ts` 并自动打开；输入中文代码、未保存时改名父文件夹，核对标签、撤销可用状态与落盘恢复草稿的新路径；有未保存子文件时删除被阻止；取消后保存到新路径，文件改名后继续查找替换保存，磁盘内容核对一致；新建重名文件拒绝覆盖。
- 删除验收：将包含已打开代码的文件夹移入系统废纸篓，相关干净标签自动关闭；访达显示该目录与子文件，实际执行「放回原处」，核对恢复文件内容一致；手动刷新后树重新出现。恢复库验收前后均为空，其他验收文件保持不变。

Windows/Linux 原生回收站、平台权限矩阵、大小写文件系统矩阵尚未实际验收。大规模目录批处理、跨目录移动、多选、引用自动更新不在本轮范围。
