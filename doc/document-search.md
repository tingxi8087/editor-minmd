# 文档查找、模式快捷键与设置

更新：2026-10-16。

## 查找入口与范围

文档和阅读模式的标签操作行提供「查找」，也可按 ⌘/Ctrl + F。顶部出现单行紧凑查找栏；文档模式可展开第二行替换，阅读模式与内置指南只显示查找。源码模式继续使用 CodeMirror 自己的查找替换。

输入字面文字即匹配，支持区分大小写、匹配计数、全部高亮、当前匹配标记与循环上一处/下一处。查找框 Enter 下一处、Shift + Enter 上一处，Esc 关闭。输入法选字的 Enter 不执行导航。打开时可用已选中的短单行文字预填；再次 ⌘F 聚焦已有查询。

搜索实际文档文字，包含标题、列表、引用、表格单元格和代码源码；可跨粗体/斜体等内联标记，但不跨段落、单元格、图片或其他非文本节点。代码块的语言、复制按钮、图片替代文字和 Mermaid 生成图形的 SVG 文本不计入搜索。命中 Mermaid 源码时自动展开源码定位。

目前不提供正则或全字匹配。高亮使用编辑器 Decoration，查询与导航不写入 Markdown、草稿正文或撤销历史。关闭查找/切换标签会清理高亮；文档与阅读间切换保留当前查询，进入源码后关闭文档查找栏。

## 替换

仅文档编辑状态提供「替换」「全部替换」。阅读模式、内置指南及繁忙/关闭确认状态禁用修改；底层替换也校验编辑器可编辑性。

替换文本按字面处理，空字符串表示删除；`$&`、反斜杠没有替换模板含义。跨内联格式的匹配使用匹配起点的文字样式，保留段落、表格等外部结构。全部替换一次事务、一次撤销，撤销/重做后结果重新计算。替换产生的新匹配不会在同一次操作中递归处理。

## 模式快捷键

| 快捷键 | 模式 |
| --- | --- |
| ⌘/Ctrl + 1 | 文档 |
| ⌘/Ctrl + 2 | 阅读 |
| ⌘/Ctrl + 3 | 源码 |

三种模式已合并为一个紧凑下拉选择框，快捷键保持 ⌘/Ctrl 1/2/3；模式统一应用于所有 Markdown 标签，新开文件和重启恢复沿用该偏好。普通文本/代码保持源码编辑；包含不支持语法的 Markdown 仍停留源码并提示，避免有损转换。打开设置或其他对话框时不执行模式切换。切换本身不保存文件，沿用现有跨模式内容与撤销策略。

## 设置与默认打开方式

设置提供「默认打开方式」「快捷键」「关于」三个页签。快捷键按文件与工作台、模式与查找、编辑内容及插入菜单分组，并说明桌面专用命令与 ⌘B 的侧栏用途。

HTML 已从可勾选扩展名、原生默认关联白名单及 macOS 安装包的文本类型声明移除。此前保存的 HTML 勾选项读取时过滤；现在共 31 个可选扩展名，安装包声明 30 个（`.ts` 非文本歧义保护继续保留）。本轮不会修改系统已有的 HTML 默认应用；HTML 文件仍可通过「打开文件」作为源码编辑。

## 验证

- 前端 18 个文件、270 项全量测试通过，包含 16 项查找专项、34 项真实工作台集成、11 项设置/关联测试。覆盖跨标记与结构边界、Unicode/字面字符、计数/大小写/循环、输入法保护、全部替换一次撤销/重做、只读保护、按钮键盘激活、焦点、tab 切换清理和不支持语法保留。
- Rust 31 项通过；关联请求校验明确拒绝 html，前端白名单与 macOS 声明逐项对齐。
- macOS 独立 QA 原生窗口：⌘1/2/3、⌘F 和源码原有查找正常；5 处中文匹配覆盖跨粗体、表格、JavaScript 和 Mermaid 源码；全部替换后 ⌘Z 一次恢复并回到干净状态；再次替换并保存后核对磁盘五处文字与表格/围栏，再关闭重开查找仍为五处。
- 阅读模式无替换入口，定位到 Mermaid 自动展开源码且未产生修改；设置页签含快捷键，31 项默认勾选中代码组为 19 项、没有 HTML，测试未批量修改系统文件关联。
- 浏览器检查浅色编辑与深色阅读布局，匹配文字使用正文墨色，避免代码高亮颜色与查找背景混合后对比不足。
- 正式桌面构建通过 `npm run build` 导出到版本目录；查找不包含浏览器原生页面搜索。
