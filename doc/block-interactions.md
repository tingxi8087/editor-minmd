# 代码块与表格交互

更新：2026-10-16。文档模式沿用紧凑纸墨布局；相关控件不改变 Markdown 的文件格式。

## 空内容

正文占位提示只显示在顶层空段落。空代码块不显示正文提示，输入区域有最小高度，语言与复制按钮独占顶栏。空表格单元格不显示正文占位。空 Mermaid 显示输入提示，不进行图形解析，也不把空内容当作语法错误。

## 代码块

- 顶栏点击语言名称，搜索中文显示名或英文语言名；可输入 1–40 字符的自定义类型（字母、数字、`_ + . # -`）。自定义类型保存在代码围栏中，未注册的语言不保证语法高亮。
- 「复制」仅复制源码，不写正文；「删除」移除当前代码块，可一次撤销恢复。
- Mermaid 编辑时默认显示源码与预览；「图表」收起源码，「源码」恢复编辑。阅读模式默认显示图形，可「查看源码」。切换视图不修改正文，语法错误时保持源码可见。
- 代码块开头向上键可插入前置段落，末尾向下键可进入后续段落；连续空行后的回车、⌘/Ctrl + Enter 可退出到正文，空代码块 Backspace 可还原正文。具体行为沿用 Tiptap 的代码块键盘规则。
- 阅读模式保留复制和查看源码，隐藏语言修改、删除等编辑操作。

## 表格

- 表格右侧、底部的加号在悬停或焦点进入时显示，分别在末尾追加列、行。
- 单元格右键打开紧凑菜单：上下插行、左右插列、列左/中/右对齐、删除当前或选中的行列、删除整表。删除项悬停或键盘聚焦时标记影响范围。
- 对齐作用于所选列的所有行，包括表头，保存为普通 Markdown 的 `:---`、`:---:`、`---:`；重开后恢复。
- 支持单元格选区及按选区批量删除。选中所有行或列再删除时移除整表，可撤销。
- 拖动列边界调整列宽；宽表在自身容器横向滚动。列宽是当前编辑视图的属性，普通 Markdown 不保存像素宽度，重新解析或打开时恢复默认宽度。
- 菜单支持上下、Home/End、Enter、Escape，靠近窗口边缘会调整位置。阅读模式隐藏加号和拖动柄，不提供编辑菜单。

## 实现边界

没有增加合并单元格、跨行/跨列布局等普通 Markdown 无法稳定表达的操作。高亮块、折叠块继续排除。表格与代码块的鼠标控件不进入正文序列化，交互修改使用现有文档撤销历史。

## 本轮验证

- 前端全量 17 个文件、246 项测试通过；包含 19 项表格专项、15 项代码块/Mermaid、4 项空内容和块边界，以及已保存文档仅改变选区不变脏的会话回归。
- 空代码块的回归测试先在原实现失败：代码块外层被写入正文占位文字；限定提示内容与 CSS 目标后通过。保存快照前完成结构插件规范化，防止第一次打开菜单时补尾段落并误标未保存。
- 构建版浏览器实际拖动第一列边界，DOM 列宽随拖动更新；验证加行加列/撤销、整列对齐、键盘删除范围预览、语言搜索与自定义/撤销、Mermaid 图表焦点隔离、阅读模式隐藏编辑入口。
- macOS 独立 QA 应用实际打开中文测试文件，右键设置列对齐、底部加行并保存；核对磁盘 Markdown 的列对齐标记和新增空行，关闭重开后表格、代码与图形仍正常。删除代码块后一次撤销恢复，并回到已保存状态。新建空文档插代码块、撤销回正文均正常。
- `npm run build` 构建桌面应用，导出到 `build/<版本>/<目标>/`。截图和测试日志保存在本地 `artifacts/`，该目录不入库。

未将 Windows/Linux 原生交互、所有输入法或复杂合并表格视为已验收。像素列宽不写入 Markdown。
