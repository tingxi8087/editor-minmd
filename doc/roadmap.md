## 1. 本地文件工作台

- [x] 打开目录、按需展开文件树，并允许独立打开目录之外的 Markdown 文件；刷新/关闭目录保留标签。
- [x] 目录内新建文件/文件夹、重命名；删除进入系统回收站。详见[目录文件管理](file-management.md)。
- [x] 多标签：独立正文、修改标记、选区、滚动位置、阅读模式和撤销历史；重复路径激活已有标签。
- [x] 关闭单个/其他标签；关闭窗口/退出时逐份检查未保存文档；另存为不能覆盖其他已打开标签。
- [ ] 复制路径、在系统文件管理器中显示、标签排序。
- [ ] 拖入文件或目录，记录最近文件与目录，快速打开文件。
- [ ] 调整侧栏宽度；维持当前紧凑布局。

验收：目录与单文件入口都可使用；切换、重命名或关闭文件不会串内容、撤销历史或丢失未保存修改；大目录不因一次性递归加载卡住界面。

## 2. Markdown 常用操作补齐

- [x] 空段落 `/` 插入菜单、键盘选择与过滤；补表情、日期、本地文档引用和链接，见[斜杠插入](slash-menu.md)。
- [ ] 选中文字后的浮动工具栏。
- [x] 插入、编辑和移除链接；网页由系统浏览器打开，本地 Markdown 用标签打开，支持标题锚点。
- [x] 相对路径图片预览；选择/粘贴/拖入图片，保存到文档旁 `assets/` 并插入相对链接（Finder 实际拖放仍待人工验收）。
- [x] 未命名文档先保存再插图；另存到其他目录时改写相对引用，原资源保留。
- [ ] 图片替换、替代文字编辑、未引用附件清理；扩充真实系统拖放和剪贴板来源验收。
- [x] 表格行列增删、整列对齐、删除范围预览与临时列宽；见[交互说明](block-interactions.md)。
- [x] 代码块语言搜索/自定义、复制和删除，空内容提示修复。
- [x] Mermaid 本地图形预览、编辑/阅读源码切换、错误保留与浅深色适配。
- [ ] 标题折叠、专注模式、工具栏隐藏。
- [ ] 粘贴清理规则和真实剪贴板样本验证。
- [ ] 扩充 Markdown 方言样本，完善未知语法保留或转源码编辑策略。

验收：编辑、保存、重开后标题/任务/表格/代码/链接/图片一致；整目录移动后相对资源可用；未支持内容不静默丢失；中文输入法、撤销与选区操作可靠。

## 3. 源码、普通文本与代码

- [x] 接入 CodeMirror 6；支持 Markdown 源码编辑，替代只读原文入口。
- [x] 明确模式切换的内容权威与撤销策略；保留模式内选区，不映射两个内核的语义光标。
- [x] 普通文本与代码按扩展名选择语言，也可手动切换。
- [x] 高亮、行号、括号匹配、缩进、折叠、自动换行。
- [ ] 显式多光标操作入口及快捷键说明。
- [x] 源码模式文件内查找替换。
- [ ] 跳转行、文档模式查找、目录搜索和结果定位。
- [ ] 编码和换行符显示/选择，支持按指定编码重新打开，例如 GB18030。
- [ ] 大文件策略与实际性能测量，避免把读取限制当作性能承诺。

优先语言：JS/TS、JSON、HTML/CSS、Rust、Python、Shell、YAML。

验收：修改源码再回文档模式内容一致；切换本身不写盘；未知语法有可靠保留路径；普通文件的编辑不误走富文本序列化。
