# 扩展 Markdown 阅读

更新日期：2026-10-17。

## 使用

在顶部模式选择框选择「阅读」，或按 ⌘/Ctrl 2。阅读直接解析当前 Markdown 原文，不再依赖 Tiptap 文档编辑器，特殊语法不会阻止整篇查看。按 ⌘/Ctrl 3 编辑源码，修改后切回阅读即可查看最新内容。

| 语法 | 阅读行为 |
| --- | --- |
| 脚注 | `[^name]` 与定义、内联脚注；自动编号，引用和返回箭头双向跳转 |
| 数学公式 | `$...$` 行内、`$$...$$` 块公式；本地 KaTeX 渲染，错误公式显示原文 |
| GitHub 提示块 | NOTE / TIP / IMPORTANT / WARNING / CAUTION，显示类型和内容 |
| 容器 | `::: tip 标题` 等带类型容器，可嵌套；未知类型保留类型名并展示内容 |
| 双链 | `[[文件]]`、`[[文件#标题]]`、`[[文件|别名]]`；没有后缀默认 `.md`，相对当前文档定位 |
| 嵌入 | `![[图片.png]]`、`![[文档]]`、`![[文档#标题]]`；图片支持 PNG/JPEG/GIF/WebP，文档可按标题截取章节 |
| HTML | 安全 HTML 展示，支持 details/summary 和行内 kbd 等；注释隐藏但原文保留 |
| 未知内容 | 普通未知标记作为文本显示，未知语言围栏保留代码；未闭合公式显示原文，不因某一块失败阻止其余内容 |

原有标题、大纲定位、表格、任务状态、代码高亮/复制、Mermaid、图片和链接仍可阅读。任务框只展示状态，不能在阅读中修改。Mermaid 失败保留图表源码；沿用本地严格渲染与图像隔离。

⌘/Ctrl F 查找阅读正文，支持大小写、上一处/下一处和 Enter/Shift Enter。检索可跨行内格式，包含展开的嵌入内容；不提供替换。查找使用 DOM Range 与 CSS Highlights，不改写 Markdown，也不插入搜索标记到正文。单次最多定位 10,000 处匹配。

公开混合示例：[扩展语法阅读](../examples/扩展语法阅读.md)。

## 原文与模式保护

- 打开、阅读、查找、切换、关闭及无修改保存不重写原文件；BOM、Frontmatter、CRLF、末尾空行保留。
- 阅读不改变正文权威来源。源码修改后阅读使用最新源码；返回文档编辑必须重新校验并同步，不能恢复过时的编辑器内容。
- 文档模式暂不新增这些语法的所见即所得编辑。进入文档时如无法完整承载，保留当前阅读/源码视图，并提示可以阅读或源码编辑。
- 保护判断基于 Markdown token，跳过围栏、缩进与行内代码及转义示例；`build/<version>/` 不再误判 HTML。保护提示与转换失败提示不重复显示。
- 统一阅读偏好应用于已有、新开和重启恢复的 Markdown，包括含特殊语法的文件。普通文本与代码继续使用源码编辑。
- 文档模式实际修改后仍可能规范化格式；本轮不承诺任意富文本修改的逐字符保真。

## 本地资源与安全边界

嵌入只读本地 Markdown，不创建标签、不启动浏览器、不写盘或注册嵌入文件为已打开文档。原生入口要求来源文档已打开或保存；拒绝远程嵌入、非 Markdown、无效 UTF-8、二进制和末级符号链接。单个嵌入最多 1 MiB；阅读侧总嵌入文本最多 1,000,000 字符，最多展开 3 层、12 个嵌入。按规范路径检查循环，失败保留可点击链接与原因，不影响正文。

嵌入内容中的相对图片和链接以该嵌入文件为基准，嵌套文档继续使用各自位置。主文档另存为到其他目录时，双链/嵌入文件路径与标准 Markdown 引用一起改写，别名与标题部分保留；代码示例不改写。

HTML 经过 DOMPurify 过滤，脚本、事件、iframe、表单、任意样式和伪造的预览资源属性不会进入阅读视图；注释不显示。KaTeX 禁用信任模式。不支持任意 HTML 的交互执行或对原文的富文本回写。图片读取沿用现有资源限制。嵌入文件目前随阅读视图重新进入/原文变化而重新读取，没有单独的嵌入文件实时监听。

无法识别边界的未知方言不承诺专有排版；其可见标记按文本显示，源码始终保留。这与为所有 Markdown 方言提供完整语义支持不同。

## 实现

- `MarkdownReader/render.ts`：Markdown-it、脚注/容器、公式、提示块、双链、原文回退与安全过滤。
- `MarkdownReader/index.tsx`：独立阅读、资源水合、有限嵌入、链接、阅读查找与滚动。
- `workspace/model.ts`：阅读偏好、文档转换保护、源码权威与资源调用。
- `resources.rs`：无副作用的本地嵌入读取。
