# Markdown 图片与链接

更新日期：2026-10-15。本轮在既有紧凑纸墨工具栏上增加两个按钮，不增加固定工具行。

## 使用方式

- 图片按钮选择本地图片；也可在正文粘贴剪贴板图片，或将图片拖到正文区域。
- PNG、JPEG、GIF、WebP，单张最多 20 MB。图片复制到当前文档目录的 `assets/image-随机名.扩展名`，Markdown 存相对路径，不内嵌 Base64。已有文件不会被同名覆盖。
- 未命名文档插图时先出现原生保存对话框。取消保存就不导入图片；取消图片选择不改变正文。
- 支持相对路径、`../`、绝对文件路径、`file:` 图片，以及 HTTP(S) 远程图片。图片不可读取或无法解码时显示占位提示，保留 Markdown 引用；远程图片会直接请求原地址，不会自动下载到 assets。
- 选中文字后点击链接按钮，或按 ⌘/Ctrl K，输入网页地址、相对 Markdown 路径或 `#标题锚点`。光标位于链接中时可修改、移除或打开链接。无选中文字时可以填写显示文字。
- 编辑模式用 ⌘/Ctrl + 点击打开链接；阅读模式直接点击。网页链接交给系统浏览器，本地 Markdown 通过已有标签控制器打开，重复路径激活原标签，保留未保存内容。缺失文件给出错误提示。
- 标题锚点使用小写、空白转连字符，去除标点并保留中文；重复标题依次追加 `-1`、`-2`。不承诺兼容所有 Markdown 方言的标题 ID。

## 另存为与移动

跨目录另存为时，将相对图片和本地链接改写为从新文件出发的路径，继续指向原资源；保留查询部分和标题锚点，编码中文、空格和括号。仅改写文档结构中的图片 src 和链接 href，不搜索替换代码块或普通正文。包含这些资源的未修改文档另存为时也会经过 Markdown 序列化，排版空行等可能规范化。

另存为不复制整个 assets，也不移动/删除原资源。要迁移文档集合，应连同引用的目录一起移动；单独移动一个 Markdown 文件无法带走其外部依赖。跨 Windows 盘符时退回绝对 file URL，该情况仅有路径单元测试，尚无 Windows 原生验收。

会话内部保存 `resourceBase`，编辑器及撤销历史继续使用打开时的引用基准。文档导出和写盘按当前文件路径转换；新插入的图片/链接也转换到会话基准。这条规则用于文档模式，另存为不重建富文本编辑器、不清空其历史。源码模式按语法树定位标准 Markdown 链接/图片/引用定义的 URL，只改路径区间；跳过 Frontmatter、代码及 HTML，保留其他原始字符。源码路径改写后重建源码会话并重置其撤销历史，避免撤销回旧目录引用。普通文本/代码另存为不进行 Markdown 资源改写。详见[源码编辑说明](source-editing.md)。保存路径与资源基准的原生登记在最后一个引用它们的标签关闭时释放。

撤销插图只撤销文档中的引用，assets 文件保留，避免删除被其他文档使用的文件；自动清理未引用附件尚未实现。图片替换、替代文字编辑、尺寸调整、SVG，以及非 Markdown 本地链接打开尚未提供专门入口。

## 实现入口

- [ResourceTools](../src/components/ResourceTools/index.tsx)：紧凑按钮与链接弹窗。
- [localImage.ts](../src/components/DocumentEditor/localImage.ts)：只影响显示的图片 NodeView，异步加载与缺失占位，不把数据 URL写回文档。
- [resources.ts](../src/lib/resources.ts)：结构化引用遍历、文件 URL 与路径换算。
- [model.ts](../src/workspace/model.ts)：插图、剪贴板、文档链接与保存会话。
- [resources.rs](../src-tauri/src/resources.rs)：原生选择图片、读取/复制、格式和大小检查、另存为路径改写、网页/本地文档访问。

本地读取以已打开/已保存的文档登记为入口，允许 Markdown 正常使用 `../` 引用目录外资源；不以工作目录为唯一资源边界。仅返回受支持的栅格图片；不开放整个磁盘的 asset 协议。写入 assets 时拒绝已有符号链接目录。

原生拖放采用 [Tauri 的 onDragDropEvent](https://v2.tauri.app/reference/javascript/api/namespacewebview/)，图片显示采用 [Tiptap NodeView](https://tiptap.dev/docs/editor/extensions/custom-extensions/node-views)。

## 本轮验证范围

前端测试涵盖链接弹窗的插入/修改/移除、阅读点击、剪贴板字节、原生拖放事件与正文区域过滤、缺失图片占位、未保存文档的保存取消、读取基准、跨目录另存为、撤销保留、链接去重与错误；Rust 测试涵盖图片格式/大小、独立随机文件、assets 符号链接拒绝、编码路径解析、相对引用改写和危险网页协议拒绝。原生 API 在组件测试中使用替身。

macOS 实际窗口已验证中文路径图片显示与缺失占位、阅读模式打开本地文档及标题、原生选图写入 assets、跨目录另存为、关闭后重新读取、整套目录复制到新位置后图片及本地链接仍指向新集合、系统“预览”复制 PNG 后粘贴并保存；同时核对了磁盘 Markdown 和生成图片。Finder 实际拖放、Windows/Linux、真实剪贴板的其他格式来源尚未人工验收。
