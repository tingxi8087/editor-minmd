# 自定义背景与侧栏精简

实现与验收日期：2026-10-15。

## 使用

左侧底部「背景设置」打开 300px 宽的非模态浮层，不增加常驻工具栏，也不改变编辑区尺寸。选择本地图片后立即预览；模糊范围为 0—24px，遮罩范围为 0—90%，拖动或键盘调节后自动保存。浮层可通过关闭按钮或 Escape 收起。

支持 PNG、JPEG、WebP，文件最多 16 MiB、单边最多 8192px、总像素最多 3200 万。图片使用居中覆盖布局。默认参数是模糊 6px、遮罩 30%。「恢复默认」移除背景，恢复这两个参数；保留当前浅色/深色主题与侧栏显隐。

选择器取消不会替换背景；图片损坏、格式或尺寸不支持时显示错误，继续保留旧背景。没有图片时滑块禁用。保存失败会保留本次预览并提供重试，不能将预览误认成已持久化。

左侧原「已打开」列表已移除。侧栏只保留文件树/大纲，打开的文件通过顶部标签切换；原多标签内容、选区、撤销、关闭及快捷键流程继续沿用。

## 纸面清晰度

图片单独位于窗口底层，仅图片应用模糊，遮罩颜色跟随当前主题。编辑正文/阅读/源码区域固定使用 92% 不透明度的纸面；标题栏、侧栏等工具区使用更轻的衬底。文字和编辑器本身不应用透明度或滤镜，代码行号、搜索栏与设置浮层保留明确底色。

即使将模糊、遮罩都调到 0，也不移除正文纸面保护。没有提供正文透明度、背景位置或动态背景的专用设置；这些不属于本轮范围。当前保留紧凑 40px 标题栏、32px 标签栏、34px 工具栏和 22px 状态栏。

## 本地文件与持久化

背景独立于文档和草稿，由 Rust 原生服务管理；没有把图片或背景参数写入 Markdown、代码文件或文档恢复快照，也不会上传背景。

macOS 数据位于 `~/Library/Application Support/io.github.tingxi8087.editor-minmd/background/`；其他平台使用 Tauri 对应的应用数据目录。

- `background-v1.json` 保存版本、受管图片标识、原文件名、模糊和遮罩。原图绝对路径不需要持久化。
- 受管 `image-…` 文件保存经过校验的图片副本。原图移动/删除不影响下次启动；图片以本地数据 URL 显示，不增加任意本地路径读取权限。
- 读取上限后检查实际格式、尺寸并完整尝试解码；解码内存上限 128 MiB。图片处理使用 [image](https://docs.rs/image/0.25.10/image/) 库。新图片写入并同步后，原子替换背景清单，再清理旧的受管图片；失败时不预先删除旧背景。
- 参数调整立即预览，写入串行合并到最新值，只更新小清单。关闭标签/正常退出会等待最后一次参数保存；恢复默认等待旧写入结束，避免旧值覆盖默认值。
- 恢复默认先提交空图片清单，再清理受管图片；清理失败单独提示，不能把已保存的默认设置回滚。只清理受管名称，不删除原图或目录内其他文件。
- 清单损坏或受管图片丢失时回到默认纸面并提示错误，保留磁盘设置以便重试/重新选择/明确恢复默认。受管目录、清单和图片的符号链接受保护。

浅色/深色和侧栏偏好仍由原有 Zustand/localStorage 管理；背景图片与参数以原生清单为准。强制结束可能丢失尚未完成的最后一次参数写入；不承诺断电持久性，也未进行大图内存/渲染性能矩阵测试。
