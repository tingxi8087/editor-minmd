# 侧栏布局

更新日期：2026-10-16。

文件树每级缩进从 12px 缩为 8px，大纲从 10px 缩为 8px。保留图标、展开箭头、行高和省略提示，不新增工具行。

侧栏右边界提供 7px 拖拽命中区，悬停/拖动时显示细线。文件与大纲共用同一宽度；默认 190px，可调 160–480px，同时为右侧正文至少保留 320px（另留 38px 活动栏）。窗口缩小时临时限制显示宽度，恢复大窗口后可恢复原先的偏好宽度。

拖拽中即时预览，松开后写入现有 `minmd-appearance` 设置的 `sidebarWidth` 字段，重启或收起/展开侧栏沿用。双击分隔线恢复 190px；聚焦分隔线后可用左右方向键每次调整 10px，Shift 加速为 40px，Home/End 调到上下限。旧设置无该字段或值无效时回落默认宽度。

Escape、指针取消、丢失指针捕获或应用失焦会取消尚未完成的拖拽，保留原宽度；卸载/收起侧栏会清理拖拽光标与选区锁定，不写入中途状态。

实现：[WorkspaceSidebar](../src/components/WorkspaceSidebar/index.tsx)、[settings](../src/store/settings.ts)、[文件树](../src/components/FileTree/index.tsx)。

自动化测试覆盖拖拽两个方向、最终坐标、只在松开时持久化、上下限与窗口缩放、取消/失焦/卸载清理、键盘调节、双击复位、多指针隔离和设置重载。

本轮验证：23 个前端测试文件 / 325 项通过，TypeScript 检查通过。隔离 macOS QA 应用实测拖拽从 190px 调到 313px、多级目录文件名展示、双击复位、键盘调宽、文件/大纲共用宽度、⌘B 收起展开、正常退出重启保留 210px；深色模式下也验证了宽度上限 480px。验收只使用独立 QA 数据，未修改生产应用设置。
