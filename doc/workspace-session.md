# 重启恢复工作区

更新日期：2026-10-16。

桌面应用启动后自动恢复上次工作目录、已保存文件标签的顺序，以及上次激活的文件。沿用现有文件树和顶部标签，无新增常驻工具栏或侧栏区域。Markdown 的文档/阅读/源码模式也会保留；普通文本和代码仍使用源码编辑器。

## 行为约定

- “已保存标签”指已有本地路径的文档，包含目录外独立打开的文件；内置指南和未命名草稿不进入文件标签记录。
- 启动从磁盘读取文件最新内容，恢复后的磁盘标签保持干净。未保存编辑仍由原有草稿保护提供恢复入口，不自动覆盖磁盘、不自动丢弃草稿；如原文件标签已恢复，再恢复其草稿会保留为恢复副本。
- 保留文件标签的先后顺序。恢复上次激活的文件；若该文件失效或上次激活的是未命名草稿/指南，则选择第一个可恢复的文件。没有恢复文件时显示空工作台；首次启动仍展示指南。
- 关闭单个或全部标签会更新记录；显式关闭工作目录会记为无目录。退出窗口/菜单退出时，保留清理前的完整标签列表；逐份确认保存可能临时激活其他文档，记录仍以发起退出前的激活标签为准。
- 打开、保存、另存为、文件树改名/回收站删除、目录切换、模式和激活标签变化会更新记录。元数据 200ms 防抖、最长 1 秒等待；焦点变化和正常退出时立即刷新。编辑正文不会反复写工作区记录，正文保护由草稿库负责。
- 启动恢复期间阻止重复文件操作；系统打开事件排队到恢复结束后处理，用户此次指定打开的文件随后激活。

## 失败处理

每个文件和目录独立恢复。已删除、移走、权限不足、文件类型变化、非 UTF-8、二进制或超过 16 MiB 的文件不会阻断其他标签；紧凑提示条说明失败项，完整列表可悬停查看，并提供重试与关闭提示。

重试不会替换已经打开的脏标签，也不会切换用户后来选择的工作目录。部分恢复失败后不立即用剩余项覆盖旧记录；后续主动改变工作区元数据时以当前工作区为准。外部移动的文件不会猜测新地址。

记录库损坏、版本不兼容或读取失败时保留原文件，停止自动覆盖。可重试读取，或明确点击「以当前工作区重建记录」保存当前状态。写入失败显示可重试提示；正常退出前未能保存工作区记录会保留窗口，重试成功后可继续退出。

## 存储与边界

Rust 在应用数据目录独立保存 `workspace-session.json`，与最近记录、草稿记录分开。「清空最近记录」不会影响重启恢复。记录仅含版本、目录路径、文件路径/顺序、模式和激活路径，不含正文、撤销历史或资源内容。

原生操作串行访问，同目录临时文件写入、同步后原子替换；前端串行提交，防止较早的异步写覆盖较新的激活状态。仅允许登记当前已授权打开/保存的文件和工作目录；恢复重新校验真实路径，拒绝被替换为指向其他位置的符号链接。当前最多记录 128 个文件标签，记录文件读取上限 2 MiB。

不恢复上次未保存编辑为磁盘标签、不恢复撤销历史、选区、滚动位置或文件树展开层级。浏览器仅用于界面预览，不执行桌面工作区恢复。强制终止可能丢失最后一小段尚未刷新完成的元数据，正常退出会等待写入。
